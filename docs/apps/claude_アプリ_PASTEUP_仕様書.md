# アプリ：PASTEUP（`apps/pasteup.html`）画像に画像と文字を重ねる 仕様書

## 概要

用意した画像（土台）に、画像（PNG などの透過画像も）と文字（吹き出し・台紙などの枠付きも）を重ねて、1枚の画像として書き出すツール。先天的アプリ（`builtin`）。2026-11-20に新設。

**土台の画像を選ぶ → 画像・文字を重ねる → 画面の上で動かす・大きさ・向きを整える → 書き出す**、の流れ。

- 名前：PASTEUP（印刷の「版下の貼り込み（ペーストアップ）」から。ユーザーから名前の指定がなかったので Claude が付けた。変えるときは`BUILTIN_APP_CHOICES`・`<title>`・`// PASTEUP`・一覧の空のときの見出し・カバー画像を直す）
- ランチャー表示名：`PASTEUP`（`BUILTIN_APP_CHOICES`）。カバー画像は`apps/img/pasteup.jpg`（900×506。`D:\dev\sideops_sync_verify\cover_pasteup.dart`が`icon_src/pasteup.html`のキャンバスで描いて書き出したもの）
- 1ファイル（HTML＋CSS＋JS）。外部ライブラリなし（描くのはキャンバス、操作も自前）
- `<head>`の先頭で`sideops-theme-bridge.js`（テーマ・同期の印・戻るボタン）を読み込む
- 外部のAPIは呼ばない。書体だけ Google Fonts から読み込む（読み込めなければ端末の書体）

### ユーザーの依頼（2026-11-20）

- 用意した画像に「任意の画像（png など透過画像も）」「任意のテキスト（吹き出しや台紙などフレーム有も可）」を挿入するツール
- SIDE-OPS の中のアプリとして作る

### 追加の依頼（2026-11-20・2回目）

1. 漫画のセリフ用に、吹き出しの種類を増やす（手書きっぽいものも）→「枠の形」に爆発・ふるえ・ウニフラ、「線の種類」に手書き風・点線、ひな形を8つ追加
2. 外部の書体を取り込めるように → ファイル（.ttf など）と Google Fonts の名前（「書体の取り込み」）
3. 画像を足すときに、背景を透過するかを決められるように →「背景を透過する？」の画面（STAMPWORKS の透過の処理をそのまま使う）
4. 画像にフィルター、任意の範囲にモザイク → 画像ごと・下の画像のフィルター、［＋モザイク］（モザイク・ぼかし・塗りつぶし・すりガラス・湯気・光の帯）

### 追加の依頼（2026-11-22）

- 「ひな形」はテンプレートのこと。最初はちょっとだけにして、あとはユーザーが足していく方法に。テンプレートはデバイス間で共有したい → 呼び名を「テンプレート」にそろえ、同期する。ユーザーの答え：最初は4つ・残りは「見本集」から足す・最初の4つも消したり直したりできる
- 追加した文字や画像を、ほかの作品（別の下の画像）にも貼り付けたい →「コピー」「全部コピー」「貼り付け」（Ctrl+C／Ctrl+V）
- 消しゴム機能（不可能なら白のマスキングのような疑似的なもの）→ 本物の消しゴム（透明にする）と色のペンの両方。ユーザーの答え：消せるのは重ねた画像・下の画像・文字／吹き出しのすべて、消し方は「両方」

## 画面

### 一覧

```
┌ // PASTEUP ─ [＋ 漫画のページ] [＋ 新しく素材を作る] [＋ 新しく編集する] [☰] ┐
│ [見本] [見本] [見本] …                               │
│  名前  1200×800・重ね 5・日時  […]                   │
└──────────────────────────────┘
```

- 作品のカード（見本の画像・名前・大きさ・重ねた数・最後に変えた日時）。新しい順
- 見本を押すと開く。［…］：開く・名前を変える・複製する・削除する（確認。元に戻せない）
- ［＋ 新しく編集する］（2026-11-26 に「新しく作る」から改名）：土台にする画像を選ぶと、作品を作ってすぐ編集の画面を開く。名前はファイル名（拡張子を除く）
- PC は画面に画像をドラッグ＆ドロップしても作れる
- ［＋ 新しく素材を作る］（2026-11-26）：素材パックがなければ名前を聞いて作り、「素材をつくる」の画面へ。あれば素材パックの一覧を開く（「素材を足す」か「＋ 新しいパック」）
- ☰：素材パック（読み込み・書き出し）・素材の管理・テンプレートの管理・書体の取り込み・管理・使っている容量を見る

### 編集の画面（`.editor-overlay`）

```
┌ [← 一覧] 名前  保存済み [↶][↷][＋画像][＋文字][＋モザイク][書き出す][☰] ┐
│                                    │ レイヤー（上ほど手前）  │
│        土台の画像＋重ねたもの        │  文字 ただいま！ [見][動]│
│        （はみ出した部分は暗く）       │  画像 star.png   [見][動]│
│                                    │  下  下の画像 1200×800   │
│                                    │ 調整（選んだものの設定）  │
└──────────────────────────────────┘
```

- 幅760px以下（スマホ）：右の欄は下へ（高さ44%）。「レイヤー」「調整」をタブで切り替える。レイヤーの一覧で選ぶと「調整」に移る
- 名前を押すと名前を変える
- ［← 一覧］・スマホの戻るボタンで一覧へ（自動で保存しているので、そのまま閉じる）
- ☰：名前を変える・下の画像を差し替える・この配置で別の画像を使う（複製）・書体の取り込み・管理
- スマホ幅では、上のボタンが2段になる
- レイヤーの一覧のいちばん下「下の画像」を押すと、下の画像のフィルターを調整できる

### 画面の上での操作

- 押す：いちばん手前のものを選ぶ（隠したもの・固定したものは選ばない。一覧からは選べる）。何もないところで選ぶのをやめる
- ドラッグ：動かす。画像の縦・横の中央に近づくと吸い付く（赤い点線。Alt を押しながらだと吸い付かない）
- 四隅の□：大きさ（縦横の比は保つ。モザイクだけは幅と高さを別々に）
- 上の○：回転（15°ごとに吸い付く。Alt で吸い付かない）
- ◆（吹き出しのしっぽの先）：しっぽの向きと長さ
- 2本指：大きさ・向き・位置（スマホ）
- 文字をダブルクリック（ダブルタップ）：文字の入力欄へ
- PC のキー：Delete で削除、矢印で1px（Shift で10px）動かす、Ctrl+Z 元に戻す、Ctrl+Y・Ctrl+Shift+Z やり直す、Ctrl+D 複製、Esc 選ぶのをやめる
- 文字は、□でドラッグして大きくした分を、離したときに「文字の大きさ・縁取り・線・余白・しっぽ」に移す（`bakeLayer`。スタイルの保存で大きさがずれないように）。モザイクは2本指で大きくした分を幅・高さに移す

### 画像を重ねる（［＋画像］）

- ファイルから選ぶ（一度に20枚まで）・素材から選ぶ
- 「素材にも登録する」に印を付けて選ぶと、素材にも入る
- 「足す前に、背景を透過するかを選ぶ」（初期はオン。端末ごとに覚える：localStorage `sideops_pasteup_prefs`）：オンなら1枚ごとに「背景を透過する？」の画面が出る（下の「背景の透過」）。ドラッグ＆ドロップ・貼り付け・素材の登録でも出る
- PC：画面にドラッグ＆ドロップ、Ctrl+V の貼り付けでも重ねられる
- はじめは土台の 40% に収まる大きさで真ん中（重ねるたびに少しずらす）

### 文字を足す（［＋文字］）

自分のテンプレート（見本の絵付き）を選ぶ。文字は「ここに文字」で入り、入力欄にカーソルが移る。

- テンプレート＝文字の見た目の組み合わせ（書体・色・縁取り・枠など。文字の中身は持たない）。DB `sideops_pasteup` の `styles` に入れて同期する（2026-11-20 までの「保存したスタイル」と同じもの。呼び名だけ変えた）
- 最初から入るのは4つ：吹き出し（角丸）・考え事（もくもく）・叫び（トゲトゲ）・字幕（白・黒い縁）。決まった ID（`tpl_round` `tpl_think` `tpl_shout` `tpl_caption`）で一度だけ入れ、入れた印 `__seeded__` も同じストアに入れる（印も同期する）。ほかの端末で同期のあとに開いても、もう一度は入れないので、消したものは戻らない。同期の前に初めて開いた端末では入るが、ID が同じなので2つにはならない（そのとき消してあったものは戻ることがある）
- 最初の4つも、自分で足したものと同じ扱い（並べ替え・名前・上書き・削除ができ、同期する）
- ［並べ替え・名前・削除］：テンプレートの管理（☰ からも）。「上書き」は編集の画面で文字を選んでいるときだけ出る（選んでいる文字の見た目で中身を上書き。確認あり）。削除は確認あり
- ［＋ 見本集から足す］：下の18種を出す。押すと自分のテンプレートに足す（文字はまだ置かない）。同じ名前がもうあれば足さない。入っているものは ✓、まだのものは ＋
- 調整の欄の「テンプレート」：自分のテンプレートと見本集から選んで「当てる」。「今の見た目をテンプレートに保存」

見本集（短い辺1000pxの画像のときの値。画像の大きさに合わせて大きさ・太さを変える）18種：吹き出し（角丸）・吹き出し（だ円）・縦書きの吹き出し・考え事（もくもく）・叫び（トゲトゲ）・手書きの吹き出し・手書きの四角・手書きのもくもく・爆発（ギザギザ）・ふるえ（弱気）・ひそひそ（点線）・ウニフラ（心の声）・ナレーション（四角・縦）・台紙（白・角丸）・台紙（黒・白文字）・付せん（手書き風）・字幕（白・黒い縁）・見出し（極太・影）

### 漫画のページ（2026-11-24）

ユーザーの依頼：「漫画を作りたい。コマ割りフレームの中に画像配置したい。コマ割りのデザインは可変式で」。選んだもの：コマを自由に置く（角を動かして形を作る）・間隔・枠線・余白も変える・ページは印刷の判型と縦長の Web 用。LIGHTBOX にも同じものを作る。

- 一覧の［＋ 漫画のページ］：大きさ（Web 縦長 1200×1700・1600×2263・スマホ全画面 1080×1920・B5／A5／B6／A4 の 350dpi・数字で）、コマ割り（3段・2段・4コマ・2×2・3段×2・2-1-2・大ゴマ＋2・斜めの境目・1コマ・コマなし）、余白・間隔・枠線（大きさに合わせた値が入る。短い辺の 6%・2%・0.4%）。白い下の画像（PNG）を作り、その上にコマを並べた作品にする（作品に `manga` が付く）。画素が 4096×4096 を超える大きさは作らない
- コマ（レイヤー `panel`）：角の□をドラッグで形を変える（余白の線・ほかのコマの角＝ちょうど／間隔をあけた所に吸い付く。Alt で吸い付かない）。コマを動かすときもふちが吸い付く。回転の○・2本指の拡大も使える（離したときに角に移す）
- コマの調整：画像を入れる／入れ替える（取り込みは［＋画像］と同じ）・コマに合わせる（コマを囲む四角いっぱい）・画像を外す・「中の画像を動かす」（コマを2回タップでも切り替え。ドラッグで位置、2本指で大きさ・回転、数字でも）・枠線（太さ0で枠なし・色）・中の色（白／なし／色）・左右に分ける／上下に分ける（真ん中で、ページの間隔をあけて切る。画像は元のコマに残る）・角を足す（いちばん長い辺の真ん中）／角を減らす（最後に動かした角）・四角に戻す。角は3〜16
- ［＋コマ］（漫画のページのときだけ出る）：余白の内側の真ん中に、内側の 40%×25% の四角。コマの並びの一番上（吹き出しより下）に入る
- ページの設定（下の画像を選んだとき）：余白（編集の画面に点線で出る。書き出さない）・間隔・枠線の太さと色、［全部のコマの枠線に当てる］、［コマ割りを作り直す］（2回押し。前のコマの画像を順に新しいコマに入れる）
- 吹き出し・文字・モザイク・効果・書き出し（隠し漏れの確認も）はふつうの作品と同じ

### ［＋モザイク］

モザイク・ぼかし・塗りつぶし・すりガラス・湯気・光の帯の範囲を足す。範囲より下にあるもの（下の画像・重ねた画像・文字）すべてにかかる。上に重ねたものにはかからない（顔は隠して、その上にセリフを置ける）。

- はじめは土台の 28%×18% の四角・モザイク。粗さは短い辺÷50
- 種類：モザイク（粗さ＝1マスのピクセル）／ぼかし（強さ＝ピクセル）／塗りつぶし（色）／すりガラス／湯気／光の帯。形：四角／だ円／なぞる
- なぞる（2026-11-24）：「形」の［なぞる］で、消しゴム・ペンと同じ帯（太さ・跡を全部なくす・終わる。消す／戻す／塗るは出さない）でなぞった形にする。1本なぞるごとに ↶ 1回分。線に沿って丸を押した形（丸の足し合わせ）にかかる。［終わる］で、なぞった形にぴったりの範囲（中心・幅・高さ）に直す。何もなぞらなければ四角に戻す。［なぞり直す］で足せる。四隅で幅・高さを変えると形も伸び縮みする。光の帯・湯気も形の中だけ
- すりガラス（2026-11-24）：下をぼかし（強さ）、白くくもらせ（白さ 0〜90%）、細かいざらつき（0〜100%。灰色の点を overlay で重ねる。粒の大きさは強さ×0.08 の画像のピクセル）。初めて選んだとき強さを短い辺÷40 以上にする
- 湯気（2026-11-24）：下を少しぼかし（短い辺×6%×濃さ。ふちほど薄く）、白いもや（だ円の放射グラデーション）＋縦長のかたまり＋立ちのぼる筋を重ねる。濃さ 10〜100%。形は種（seed）で決まり、［形を変える］で作り直す（編集の画面と書き出しで同じ形）。範囲のふちはくっきりしない
- 光の帯（2026-11-24。アニメの地上波で入る光の帯）：芯は真っ白（下は見えない）、外へ「光の色」でふわっと消える。下とスクリーンで重ねる。芯の太さ 5〜100%（高さに対する割合）。四角＝帯（回転で斜めに）、だ円＝丸い光。四角のまま初めて切り替えたとき、高さが幅の半分より大きければ幅×0.3 の帯にする
- 四隅の□で幅と高さを別々に、上の○で回転。「幅・高さ」に数字でも入れられる
- 画像の外にははみ出さない（書き出されない部分なので）

### 調整の欄

- 文字：中身（改行可・2000字まで）・書体（ゴシック・明朝・丸ゴシック・極太・手書き風・筆＋取り込んだ書体。いちばん下の「＋ 書体を取り込む…」で取り込みの画面へ。取り込んだら、その文字に当てる）・太字・大きさ・文字の色・縦書き・揃え（縦書きでは左＝上、右＝下）・行間・字間・縁取り（色・太さ）・影
- 枠：形（なし・吹き出し角丸・吹き出しだ円・考え事・叫び・爆発・ふるえ・ウニフラ・台紙角丸・四角）・塗り（色・濃さ。0で透明）・線（色・太さ。0で線なし）・線の種類（実線・手書き風・点線。ウニフラでは使わない）・余白・しっぽ（なし・ウニフラ以外の形に付く）
- 画像：上に加えて「背景を透過…」（あとから透過する。透過した画像を新しく保存してつなぎ替えるので ↶ で戻せる）・フィルター
- 下の画像：差し替える・フィルター。「かける相手」で［仕上がり全体］（重ねた画像・コマ・吹き出し・文字も含めて書き出す絵全体。作品の `pageFx`）と［下の画像だけ］（`baseFx`）を切り替える。漫画のページ（白い台紙）・全体フィルターだけ付いている作品では［仕上がり全体］で開く（2026-11-26）
- コマ：中の画像にフィルター（コマの `fx`）。［全部のコマに同じフィルター］でほかのコマ（画像がまだないコマも）に写す（2026-11-26）
- フィルター：見本のボタン（なし・モノクロ・セピア・あざやか・やわらか・ひんやり・あたたか・レトロ・暗く。押すだけで当たる・いまの値と同じ見本が光る。「なし」で元に戻す）、1つずつ（明るさ・コントラスト・彩度・色相・モノクロ・セピア・ぼかし）
- モザイク：種類・形・粗さ／強さ／色・幅と高さ
- テンプレート：テンプレート・見本集から選んで「当てる」（文字の中身・位置・大きさはそのまま。太さ・余白は大きさの比で合わせる）。「今の見た目をテンプレートに保存」（名前を付ける。同じ名前は上書きを確かめる）
- 画像：大きさ％・左右反転・画面いっぱいに（土台を覆う大きさで真ん中、回転0）・素材に登録
- 共通：不透明度・回転・横の中央へ・縦の中央へ・回転を0に・手前へ・奥へ・複製・コピー・削除（2回押し。↶で戻せる）

### 消しゴム・ペン（2026-11-22）

- 上の［消しゴム］（選んでいる画像・文字。何も選んでいなければ下の画像）、調整の欄の「消しゴム・ペン」（画像・文字・下の画像）で始める。モザイクには使えない
- 画面の上に帯が出る：相手の名前・［消す］（透明にする）・［戻す］（消したところを元に戻す）・［塗る］（色で塗って隠す。色を選ぶ）・太さ（画面で2〜160px）・［跡を全部なくす］（2回押し）・［終わる］
- ブラシの間は、画面をなぞると線を引く（選ぶ・動かすはしない）。相手はオレンジの点線で囲む。PC はブラシの大きさの丸が出る。2本指になったら、なぞりかけの線は取り消す
- ブラシの間にレイヤーの一覧で別のもの（画像・文字・下の画像）を選ぶと、相手が変わる。モザイクを選ぶと終わる
- 終わり方：［終わる］・もう一度［消しゴム］・Esc・スマホの戻るボタン（ブラシを先に終わる）・一覧へ戻る
- 1本なぞるごとに「元に戻す」1回分。跡があるものは、レイヤーの一覧の名前に ✎、調整の欄に「跡 n本」
- 元の画像は書き換えない。なぞった線（相手の座標）を持ち、描くたびに当てる：中身を別のキャンバスに描く → 線を順番に（消す＝destination-out／戻す＝元の中身を線の形で切り抜いて重ねる／塗る＝色の線。相手の範囲の中だけ）→ 不透明度を掛けて重ねる（`drawMarked`）
- 相手を動かす・回す・大きさを変えても、跡は付いてくる。画像を左右反転すると、跡も一緒に反転する（反転した中身の座標で持つ）。文字は、□で大きくした分を文字の大きさに移すとき、跡も同じ倍率にする。「大きさ」の数字を変えたときは跡は動かない（ずれることがある）
- 下の画像を差し替えると、前の画像に付けた跡はなくす（知らせる。↶ で戻せる）
- 書き出し：PNG では消したところは透明、JPEG では白
- 上限：相手ごとに線1500本・1本5000点・数字の合計40万（超えたらなぞれないと知らせる）

### 作品をまたいでコピー・貼り付け（2026-11-22）

- 「コピー」（調整の欄・選んでいる1つ。PC は Ctrl+C）・「全部コピー」（レイヤーの欄の上。重ねたものすべて）
- コピーしたものは localStorage `sideops_pasteup_clip` に配置だけを置く（この端末の中。同期しない。再読み込みしても残る。次にコピーするまで何度でも貼り付けられる）。画像は同じ端末の DB にある画像を指すだけ（コピーし直さない）
- 「貼り付け」（レイヤーの欄の上。コピーしたものがあるときだけ出る。PC は Ctrl+V）：別の作品でも、同じ作品でも（同じ作品なら少しずらす）。下の画像の大きさが違えば、位置と大きさを合わせる（差し替えと同じ合わせ方）。上限60個を超える分・見つからない画像は飛ばして知らせる。↶ で戻せる

- 片付け：コピーしてある画像は、コピー元の作品を消しても残す（貼り付けられるように）
- レイヤーの一覧：［見］／［隠］で表示を切り替え、［動］／［固］で固定（画面の上で選ばない・動かない）

### 縁取り・色・影／効果線（2026-11-27）

ユーザーの依頼：次に入れる機能の候補（A〜J）から「先ずはAB」。

- A：重ねた画像の「縁取り・色・影」（調整の欄）。見本［白フチ］［黒フチ］［白フチ＋影］［なし］（太さはページの短い辺の0.6%、影のずれ0.5%・ぼかし0.4%）、［1色に塗る］＋色、縁取りの太さ・色、影（色・ずれ・ぼかし・濃さ%）。影は右下45°（左右反転しても見た目は右下）。太さ・ずれ・ぼかしは調整の欄ではページのピクセル（いまの大きさのとき）で見せ、レイヤーの `deco` には画像のピクセルで持つ（画像を大きくすると一緒に太くなる）。縁取りの色を選ぶと、太さ0なら縁取りも付ける
  - 描き方：中身（フィルター・消しゴムの跡ごと）を別のキャンバスに描く → 1色に塗る（source-in）→ 縁取り（不透明度128以上の形からの距離。Felzenszwalb の距離変換で正確なユークリッド距離、半ピクセルのなめらかさ）→ 影。作った絵はレイヤーごとにとっておき（60個まで）、中身・フィルター・飾り・消し跡が変わったときだけ作り直す。大きな画像は 250万画素まで縮めて作る
- B：新しいレイヤー「効果線」（［＋効果線］）。種類［集中線］［スピード線］［ベタフラ］、本数（4〜600）・太さ（ページのピクセル）・抜け%（集中線・ベタフラは中央のだ円の空き、スピード線は真ん中の空ける帯）・ばらつき・中心の位置（横・縦%）・線の色・中の色（ベタフラ）・［形を変える］（種を変える）・［コマに合わせる］（真ん中にあるコマの枠線の内側の大きさに）・幅・高さ。範囲（w×h）の外には描かない。四隅の□で幅と高さ（モザイクと同じ）、スピード線の向きは回転
  - コマを選んでから［＋効果線］を押すと、そのコマに合わせる。漫画のページでは、コマの並びのすぐ上（吹き出しより下）に入る
  - 線の並びは種（seed）で決まり、開き直しても変わらない

### 素材パック・素材をつくる（2026-11-26）

ユーザーの依頼：漫画で使う効果音・擬音・手書きセリフなどの画像を「素材パック」にまとめ、各端末に配ってインポートして使いたい。作るのは「新しく素材を作る」で、画像生成AIで作った画像を開いて、必要な所だけ切り出し・背景を抜いて保存。ユーザーの選択：Claude のおすすめどおり（ZIP のファイルで受け渡し・3段で作る）。OneDrive の置き場は作らない（容量を圧迫するため。受け渡しはユーザーが考える）。

- 素材パック＝{ 名前・版・素材の一覧 }。作業用DBの `packs`。同期しない。受け渡しは書き出したファイル（`名前.pupack.zip`）
- ☰「素材パック」：［＋ 新しいパック］［パックを読み込む…］［今の素材をパックにまとめる］（この端末の「素材」を1つのパックに。素材はそのまま残る。分類は「その他」）。パックごとに［素材を足す］［書き出す］［共有］（ファイルを共有できる端末だけ）［名前］［削除］（2回押し）。まだ書き出していない変更があれば「まだ書き出していない変更あり」と出し、削除の2回目の文字も「書き出していません。もう一度で削除」
- 「素材をつくる」の画面（`#maker`。編集の画面と同じ作り。スマホは下に調整の欄）
  1. ［元の画像を開く］：画像を開く（保存しない。30MBまで。4096×4096 の画素数・長い辺8192pxを超えたら縮める）
  2. 囲む：［四角］ドラッグ／［なぞる］まわりをなぞる（指を離すと閉じる）。外は暗く見せる。［切り出す］か［画像全体を使う］
  3. 背景を抜く：取り込みの「背景を透過」と同じ処理（自動・白・黒・色を指定、強さ、まわりとつながった部分だけ、ふちを削る）。最初から「抜く」。なぞって切り出したときは外が透明になって背景の色を推定できないので、「自動」は なぞった線の下の色（元の画像。中央値）を消す色にする
  4. 手で直す：［消す］（透明に）［戻す］（切り出したときの色に）［動かす］・太さ（画面のpx）・［ひとつ戻す］・［手直しを全部なくす］（2回押し）。線は切り出しの座標で持ち、背景の設定を変えてもかけ直す
  5. パックに保存：名前（既定「素材 n」）・分類（効果音・擬音・手書きセリフ・記号・その他。前に選んだもの）・［透明な余白を詰める］（既定オン。透明度8以下を余白とみなし、2px残す）。保存すると囲む所に戻り、同じ画像から続けて切り出せる
  - 拡大して保存（2026-11-26）：「4. パックに保存」の［そのまま／2倍／3倍／4倍］。余白を詰めてから拡大する。処理は AI ではなく「2倍ずつなめらかに拡大 → アンシャープマスク（［シャープ］・透明な所はさわらない）→ 透明の境目を締める（［ふちをくっきり］。半透明の値を 128 を中心に 倍率÷1.4 倍に広げる）」。色のはっきりした文字・線向けで、細かい描き込みは増えない。ぼかし・光など半透明が大事な素材では［ふちをくっきり］を外す。［拡大の仕上がりを見る］で保存する絵を画面に出す（その間はなぞって直せない。手直し・設定を変えると見本はやめる）。4096×4096 の画素数を超えるときは倍率を下げて知らせる。倍率・2つの印は端末ごとに覚える（localStorage `sideops_pasteup_mkscale`）
  - 白・黒など色の付いていない背景を抜いたときは、半透明の輪郭の色から背景の色を差し引く（C = a·F + (1−a)·K として F に戻す。拡大で白い縁が目立たないように）。元が小さくて輪郭の画素そのものが白っぽいときは、「強さ」を上げるか「ふちを削る」で詰める
  - 見る背景（2026-11-26）：格子・白・黒・グリーン（#00b140）・ブルー（#0047bb）・マゼンタ（#ff00ff）。格子だけだと消し残しに気づきにくいため。「手で直す」の欄と、画面右下の［背景：〜］（押すたびに次へ）で切り替え。取り込みの「背景を透過する？」の見本にも同じ選択がある。端末ごとに覚える（localStorage `sideops_pasteup_bgview`）
  - 画面の拡大：2本指・ホイール・右下のボタン（1〜32倍）。ホイールを押してドラッグで移動。描きかけで2本目の指が来たら、その線は取り消す
  - パックの素材を押すと：名前・分類を変える／パックから外す（2回押し）
  - 戻る（← 戻る・スマホの戻るボタン）：切り出し中なら確かめてから、素材パックの一覧へ
- 「画像を重ねる」の「素材から選ぶ」：［この端末の素材］＋パックごとのタブ（パックがあるときだけ）。パックのタブでは分類で絞り込み（分類が2つ以上のとき）。選んだタブは端末ごとに覚える（localStorage `sideops_pasteup_aitab`）。パックの素材は、その画像をそのまま作品のレイヤーから参照する

ファイルの形（ZIP。書き出しは圧縮なし。読み込みは圧縮なし・deflate（`DecompressionStream`）。フォルダごと ZIP にし直した「名前/pack.json」も読める）：

```

items/001.png …（透過 PNG）
```

- 版（ver）：前に書き出したあとに変えていたら、書き出すときに1上げる
- 読み込み：同じ id のパックがあれば「今：版・枚数／読み込むもの：版・枚数（古い版なら注意・書き出していない素材が消えるなら注意）」を見せて、置き換えるか確かめる。置き換えても、作品に貼った素材は残る
- 歯止め：ファイル300MBまで・素材500枚まで・1枚20MBまで・PNG の印（89 50 4E 47）がないもの・読めないもの・4096×4096 の画素数を超えるものは飛ばして数を知らせる。`format` が違う・`v` が新しいものは読まない。ファイル名は `items/〜.png` だけ（`..` などで外を指せない）

## 文字の描き方

- 横書き：行ごとに揃え（左・中・右）。字間が0以外のときは1字ずつ置く
- 縦書き：右の列から。`ー「」（）…：` などは90°寝かせる、`、。，．`は右上に寄せる、小さい「ゃゅょっ」などは少し右上に寄せる。英数字は寝かせない（縦中横はしない）
- 縁取り：先に全部の行を太い線（縁取りの太さ×2）で描いてから、文字を塗る（縁が隣の行の文字にかぶらない）
- 影：枠があれば枠に、なければ文字に付ける

## 枠（吹き出し・台紙）の描き方

- 大きさは「文字の大きさ＋余白×2」が基準。だ円・もくもく・トゲトゲは、文字が収まるようにその1.25〜1.3倍の楕円
- しっぽは三角形（もくもくは小さい丸を3つ）。根元は枠の内側に置き、枠と1つの形にまとめて描く
- 枠としっぽを1つの形にまとめるため、別のキャンバスで「線の色で太い線（線の太さ×2）→ 内側をくり抜く → 塗り」の順に描いて重ねる（塗りを薄くしても、枠としっぽの境目の線が見えない）
- トゲトゲ・爆発・ウニフラ・手書き風のゆれは、レイヤーのIDから決めた乱数（開き直しても形が変わらない）
- 形はすべて点の並び（多角形）で作る（`framePolys`）。だ円は96点、角丸は角ごとに10点
- 爆発：とがりの長さ（1.3〜1.9倍）と向きをばらばらに。ふるえ：半径を正弦波でゆらす（細かい波の縁）
- ウニフラ：まわりに細い三角のとげ（線の色。数は周りの長さから40〜180本、長さはばらばら）、まん中のだ円を塗る。線の太さでとげの太さが変わる。線の太さ0でとげなし
- 線の種類「手書き風」：辺を細かく分けて（文字の大きさの3.5%ごと）、正弦波を重ねたなめらかなゆれで点をずらす。少しずれた細めの線（太さ×0.65）をもう1本重ねて、二度描きに見せる
- 線の種類「点線」：線の太さに合わせた点線（丸い端）

## 背景の透過

STAMPWORKS（`apps/stampworks.html`）の透過の処理（`detectKey`・`keyAlpha`・`floodRestrict`・`despill`・`erodeAlpha`・`dilateMask`・`ycc`）を、中身を変えずに写した。つなぐ部分（`cutBackground`）と、色を指定する`keyFromRgb`だけ足した。

- 「背景を透過する？」の画面：仕上がりの見本（長い辺520pxに縮めて計算）・「背景を透過する」（初期はオフ＝そのまま使う。あとからの「背景を透過…」ではオン）
- 消す色：自動（外周の色の中央値。外周の半分以上が透明なら「もう透明な画像」）・白・黒・色を指定。色の濃い背景（緑など）は色味で、白・黒・灰色っぽい背景は色の近さで消す
- 強さ（0〜100）・「まわりとつながった部分だけ消す」（初期はオン。絵の中の同じ色の部分は残す）・ふちを削る（0〜3px）
- 色の濃い背景のときは、輪郭の色かぶりも抜く
- ［この画像を使う］で元の大きさのまま計算して PNG で保存。［やめる］・背景のクリック・戻るボタンでは、その画像を足さない（取り込んだ画像も消す）

## 書体の取り込み

- ファイル（.ttf・.otf・.woff・.woff2、50MBまで）：`FontFace`で読めるか確かめてから、DB `sideops_pasteup_work` の `fonts` に保存（この端末だけ）。書体の名前（`PUF_<id>`）で登録。表示名はファイル名。名前の変更・削除（2回押し）
- Google Fonts（名前）：`fonts.googleapis.com/css2?family=名前` を読み込む。名前が違うと Google が 400 を返すので、そこで「見つかりませんでした」。名前だけを `fonts` に保存
- 書体のキー：ファイル `u:<id>`、Google `g:<名前>`。Google のキーは名前そのものなので、保存したスタイル（同期する）に入れれば、ほかの端末でも同じ書体になる。ファイルの書体は、ほかの端末では「（この端末にない書体）」と出て、ゴシックで描く（キーは残す）
- 書体を消しても、使っている文字のキーは残す（ゴシックで描く）。Google の書体は同じ名前でもう一度足せば元に戻る。ファイルの書体は取り込み直すと別のIDになるので、文字ごとに選び直す
- 注意書き：画像に使ってよいかは書体ごとのライセンスを確かめる

## フィルター

- 仕上がり全体（`pageFx`）：画面と同じ大きさの別のキャンバスに全部（下の画像・レイヤー・モザイク）を描いてから、フィルターを付けて写す。書き出し・一覧の見本も同じ `drawScene` を通るので同じ見た目になる

- canvas の `filter`（CSS のフィルターと同じ書き方）で描く。フィルターに対応していないブラウザ（古い Safari など）では効かない（調整の欄に注意書き）
- ぼかしは画面のピクセルでかかるので、いまの拡大率を掛けて指定する（画面と書き出しで同じ見え方。2026-11-20 に確かめた）
- 文字・モザイクにはかけない

レイヤー：

- 共通：`{ id, type, x, y, scale, rot（-180〜180°）, opacity（0〜1）, hidden, locked }`
- 画像：`{ type:'image', blobId, name, w0, h0（元の大きさ）, flipX, fx, marks }`
- 文字：`{ type:'text', text, st, tail:{x,y}|null, marks }`（`tail`＝しっぽの先。レイヤーの中心からの位置）
- `marks`（消しゴム・ペンの跡。下の画像の跡は作品の `baseMarks`）：`[{ m:'e'|'r'|'p'（消す・戻す・塗る）, w：太さ, c：色（塗るとき）, p:[x0,y0,x1,y1,…] }]`。座標はレイヤーの中身の座標（下の画像は画像のピクセル）。小数1けたに丸める（`normMarks` で範囲に収める）

- 効果線：`{ type:'lines', w, h, mode:'focus'|'speed'|'beta', count, thick, inner（%）, jitter（%）, cx, cy（中心のずれ %）, color, color2, seed }`（`scale` はいつも1。2026-11-27）

- モザイク：`{ type:'mosaic', w, h, shape:'rect'|'ellipse', mode:'pixel'|'blur'|'fill'|'frost'|'steam'|'light', block, blur, color, haze, grain, dens, seed, core, glow }`（`scale` はいつも1。haze・grain はすりガラス、dens・seed は湯気、core・glow は光の帯。shape:'brush' のとき strokes:[{ w, p:[x,y,…] }]（なぞったときの座標）と bw・bh（そのときの幅・高さ。今の w・h との比で伸び縮み）。作業用DBだけで同期しない）

フィルター `fx`（`baseFx`・`pageFx`・コマの `fx` も同じ）：`{ b 明るさ%, c コントラスト%, s 彩度%, h 色相°, g モノクロ%, p セピア%, bl ぼかしpx }`。既定値の項目は持たない（`normFx`）。

文字の見た目 `st`：`{ font, size, color, bold, lh, ls（字間。文字の大きさに対する割合）, align, vertical, strokeW, strokeC, shadow, frame（none/round/oval/think/shout/burst/wave/flash/plateRound/plate）, fill, fillA, line, lineW, pad, tail, lineStyle（solid/rough/dash） }`。`font` は用意した書体（sans/serif/maru/pop/hand/brush）・`u:<id>`・`g:<名前>`。読み込むときは`normSt`で範囲に収める（同期で来たおかしな値でも壊れない）。書体・枠・線の種類のキーの意味は変えない（保存したスタイルが同期されている）。`lineStyle`・新しい枠・取り込んだ書体のキーを足したので `SYNC_APP_BUILD` を 2026112003 に上げた（古い版がスタイルを読み直して、知らない値を消して書き戻すのを防ぐ）

## 歯止め（誤作動防止）

- 取り込み：画像のファイルだけ（SVG は使わない）。1ファイル30MBまで。読めない形式（HEIC など）は案内を出す
- 大きすぎる画像（4096×4096 の画素数か、長い辺8192pxを超える）は縮めて取り込み、知らせる（スマホのキャンバスの上限対策）。GIF は最初のコマだけ（知らせる）
- 重ねられるのは1作品60個まで
- 元に戻す／やり直す（80回分）。削除・スタイルを当てる・差し替えは「↶で戻せます」と知らせる
- レイヤーの削除は2回押し（キーの Delete はすぐ消すが、↶ で戻せる）。作品の削除・スタイルの削除は確認。素材から外すのは2回押し
- 片付け：開いたとき、どの作品からも使われていない画像（素材を除く）を消す。取り込んで10分以内のものは残す（別のタブで作業中かもしれない）。作品を削除したときはすぐ片付ける
- 最初の作品を作ったとき、`navigator.storage.persist()` を頼む（ブラウザが勝手に消さないように）
- 画像の外にはみ出した部分は書き出されないので、画面では暗くして見せる
- 2本指：前から選んでいたものの上でだけ、そのものを変える（うっかり大きさを変えない）。画面の拡大は保存しない（書き出しにも関係しない）
- 書体：ファイルは拡張子と50MBを確かめ、`FontFace` で読めなければ取り込まない。Google の名前は英数字とスペースだけ（URL に変な文字を入れない）。読み込みは12秒で打ち切る。同じ名前は足さない
- 背景の透過：初期はオフ（勝手に消さない）。見本で仕上がりを見てから決める。やめたら足さない
- 書き出し：モザイク・効果があるときは、隠し漏れを確かめた印を付けるまで書き出せない。なぞった形は1つの効果に400本・1本4000点まで
