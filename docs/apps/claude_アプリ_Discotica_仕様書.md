# アプリ：Discotica（`apps/discotica.html`）音楽プロジェクト管理 仕様書

## 概要

アーティスト一覧→アーティスト詳細→アルバム詳細（→楽曲一覧）の3〜4階層構造を持つ音楽プロジェクト管理アプリ。IndexedDB本実装（DB名`sideops_discotica`）。

## アーティスト一覧（トップ画面）：3Dカルーセル・リング表示

円筒の外周にカードを平らなまま貼り、カードではなく円筒（トラック）側を`rotateY`で回す、定番の3Dカルーセル方式。

- 円筒は8面（`ARTIST_RING_SLOTS = 8`、1枚あたり45度）。各カードは`rotateY(面の角度) → translateZ(半径)`で外周に配置する（カード自体は曲げない、平らなまま）
- 半径はカード幅の実測値から`(cardW/2) / tan(π/8) * 割増率`で算出。画面幅が変わる（Stageの表示モード変更等）たびに再計算する
- トラック全体を`rotateX(-14度)`で手前に傾け、斜め上から見下ろす構図にする。傾けた分だけ画面中心からずれる高さを`translateY`で補正
- 回転位置は上限のない整数（`artistRingPos`）で保持し、中央インデックスは`ringMod()`で毎回算出する。これにより末尾→先頭（またはその逆）を跨いでも、リングが逆回転せず同じ向きに1面分だけ回る
- 背面（90度より奥）を向いたカードは名前ラベルを`visibility: hidden`にする（鏡文字になるため）。円筒の面数（8）より実データが多い場合は、真裏の面に立つ1枚だけを残し、残りは非表示にして重なりを防ぐ
- 操作はホイール・クリック・スワイプ（タッチ）・左右矢印キーに対応。トラックパッドの連続ホイール入力でリングが空回りしないよう220msのクールダウンを設けている

### 最低表示枚数・NOW MASTERINGダミー埋め

円筒の面数（8枚）に実データ数が届かない場合、`NOW MASTERING`という点滅ラベルのダミーカードで埋め、リングが常に一周分成立して見えるようにする。ダミーカードは「＋アーティストを追加する」と同じ導線（クリックで追加モーダルを開く）を持つ、ラベル違いの同じボタンという位置づけ。

## 中央カード連動の背景演出

リング周辺（`.artist-cf-wrap`の範囲のみ）に、中央（フォーカス中）のカバー画像を拡大・減彩（`saturate(.35) brightness(.4) blur(2px)`）した背景を敷く。

- 2枚のレイヤーを交互に使うクロスフェード方式（片方が消えながらもう片方が浮かぶ）で切り替える。読み込みの合間に一瞬空白になることがない
- **読み込みタイミング**：回転アニメーション（0.6秒）が収まってからさらに0.65秒後。中央カードが高速に送られている最中に毎回読み込むと慌ただしいため、遅延読み込みにしている
- 連続で送られた場合は直前の予約をキャンセルし、最終的に止まった1回だけ発火する（連打の途中経過では読み込まない）
- ＋カード・NOW MASTERINGダミー・カバー画像未設定のアーティストが中央のときは、背景なし（フェードアウト）に戻す
- Blob URLは「直前の1枚だけを保持し、新しい画像に切り替わった時点で古い方を解放する」専用ヘルパー（`createSingleUrlHolder`）で管理。一覧描画用の`createUrlPool`は一覧再構築のたびに全解放される設計のため、表示され続ける背景画像の管理には使えない（別ヘルパーが必要）

## 新規追加モーダル

アーティスト名の入力欄プレースホルダーは「アーティスト名を入力」という一般的な文言（実在するアーティスト名の例示は不採用）。

## 画像の見え方（2026-10-07〜）

アーティスト・アルバムの画像を選ぶと、続けて「見え方の調整」（`apps/sideops-frame.js`。16:9の枠）を開く。［決定］で記録の`coverThumb`（`{ ar, z, cx, cy }`）に保存し、アーティストのカード・概要の画像・アルバムのカード（いずれも16:9）にその見え方で出す。［キャンセル］なら中央で切り抜き。アーティスト画像は、アーティストの詳細の概要の画像をクリックしてやり直せる。中央カードに連動する背景（ぼかした全面の画像）は、見え方を使わず中央のまま。

## アルバム一覧・楽曲一覧

現状は横スクロールのみの単純な並び（演出なし）。**循環ベルトコンベア方式（奥行きなしの2D、左右に流れて末尾→先頭が繋がる、操作した分だけ動く）への改修が要望されているが未着手。** アーティスト一覧と同様、最低表示枚数に届かない分はNOW MASTERINGダミーで埋める方針で合意済み。

着手前に、上記アーティスト一覧の実装（円筒の外周にカードを貼り、カードではなくトラック側を回す3Dカルーセル方式）を読むと、円筒方式との使い分けの意図が分かる。
