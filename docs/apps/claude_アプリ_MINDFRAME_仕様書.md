# アプリ：MINDFRAME（`apps/mindframe.html`）マインドマップ／フローチャート／UIラフ 仕様書

## 概要

1枚の無限キャンバスに、マインドマップ・フローチャート・UIラフ（画面の検討）を描く先天的アプリ（`builtin`）。作業名は「マインドマップ（仮）」。「フローチャートの作成」「UIデザインの検討」にも使えることを条件に設計した。

- 名前の由来：**MIND**（マインドマップ＝考えを広げる）＋**FRAME**（ワイヤーフレーム＝画面の骨組み、考えの枠組み）
- ランチャー表示名：`MINDFRAME`（`BUILTIN_APP_CHOICES`、カバー画像は`apps/img/mindframe.jpg`）
- テーマ追従：`<head>`で`sideops-theme-bridge.js`を読み込む。キャンバスは色を解決済みの値で描くため、`sideops:themechange`を受けて描き直す（下記「描画の仕組み」）
- 本体の`sideops:stage-closing`（Stageを閉じる合図）に対応済み（受けた時点で保存待ちを書き込む）
- 外部ライブラリは使っていない（Google Fonts のみ）。自動整列・木の配置などは定番のアルゴリズムを自前で実装

## ファイル構成

| ファイル | 役割 |
|---|---|
| `apps/mindframe.html` | 画面の骨組みとCSS。アイコンはSVGの`<symbol>`で同梱 |
| `apps/mindframe.js` | 本体（状態・描画・操作・保存・書き出し） |
| `apps/mindframe-io.js` | テキストの読み書き（箇条書き・Mermaid）と自動整列。**DOMにもアプリの状態にも触れない純粋な関数だけ**を`window.MFIO`に公開 |

Discotica（`discotica.html`＋`discotica.js`）と同じく、HTMLとJSを分けている。規模が大きい（本体約5,100行）ため、単独で検証しやすい入出力部分をさらに別ファイルにした。

## 画面構成

| 画面 | 内容 |
|---|---|
| ボード一覧 | ボードのカード（サムネイル・名前・種類・ノード数・更新日時）。検索（名前・中の文字）、種類で絞り込み、並び順（更新／作成／名前）。カードごとに複製・削除 |
| エディタ | 左：ツール欄／中央：キャンバス／右：詳細パネル（折りたためる）。上のバーにボード名・保存状態・元に戻す／やり直す・書き出し・メニュー |

**スマホ（幅640px以下）**：ツール欄は下に横並び、詳細パネルは下からのシート（「詳細」で開く）。選択中は下に操作ボタン（編集・＋子・＋兄弟・複製・削除・詳細）が出る。上のバーはロゴ・書き出し・？を隠し、書き出しと使い方は☰メニューへ。タッチ操作：1本指で画面移動、2本指ピンチで拡大縮小、ダブルタップで編集。

### 新規ボードの「はじめ方」

マインドマップ（中心トピック）／フローチャート（開始→処理→判断→はい・いいえ→終了）／UIラフ（スマホ：ログイン画面のひな形）／UIラフ（PC：トップ画面のひな形）／白紙／テキストから作成。はじめ方は最初の中身と「種類」（一覧での分類）を決めるだけで、どのボードにも何でも置ける。

## 置けるもの（ノードの種類）

| 種類 | 内容 |
|---|---|
| トピック（`topic`） | マインドマップの項目。中心トピック（根）だけ位置を保存し、子の位置・大きさは毎回自動で計算する |
| 図形（`shape`） | フローチャート用10種：処理・角丸・端子（開始・終了）・判断・入出力・書類・データベース・定義済み処理・準備・円 |
| 付箋（`sticky`） | 6色。濃い文字の不透明な紙（テーマに関係なく読める） |
| テキスト（`text`） | 幅だけ持ち、高さは文字から自動。空のまま編集を終えると消える |
| 画面フレーム（`frame`） | スマホ390×844／タブレット820×1180／PC 1440×900／自由。名前はフレームの左上に表示 |
| UI部品（`ui`） | 19種：ボタン・入力欄・検索バー・プルダウン・チェック・ラジオ・スイッチ・スライダー・タブ・画像枠・カード・リスト・アバター・アイコン・バッジ・区切り線・文章ダミー・ヘッダー・タブバー（＋文字の「見出し」「本文」） |
| 画像（`image`） | 貼り付け・ドロップ・画像ツールで置く。不透明度を変えられ、ロックすれば下敷きになる |

タブ・タブバー・リストの項目は、文字を「`|`」か改行で区切って書く。チェック・ラジオ・スイッチ・タブ・タブバーは「オン／先頭を選択中」の状態を詳細パネルで切り替える。

## 操作の要点

- **マインドマップ**：`Tab`で子、`Enter`で兄弟、矢印キーで移動、`Alt+↑↓`で並べ替え、`Ctrl+/`で折りたたみ。トピックを選んだまま文字を打つと書き換え（日本語入力もそのまま。後述）。子トピックをドラッグして別のトピックに落とすと付け替え、空いている所に落とすと同じ親の中で並べ替え。中心トピックの「枝の配置」は右／左右／下の3種
- **フローチャート**：図形のふちの○（接続点）から別の図形へドラッグでつなぐ。○をクリックするとその方向に同じ図形を作ってつなぐ（空いていなければ横にずらす）。○から空いている所へドラッグしても同じ（出した方向の軸に近ければ軸にそろえる）。線はダブルクリックでラベル。線の形は直線／カギ線／曲線、矢印はなし／終点／始点／両方
- **UIラフ**：フレームを動かすと、中に完全に入っている部品（ロック中・子トピックは除く）と、中にある線の自由な端も一緒に動く。ドラッグ中は他の要素のふち・中心にガイド線が出て吸着（`Alt`で無効）。詳細パネルで位置・サイズを数値指定。フレームの○から別のフレームへ矢印を引けば画面遷移図になる。「横に並べて複製」で中身ごと右隣にコピー
- **共通**：範囲選択（空白をドラッグ）、`Shift`/`Ctrl`で追加選択、`Space`＋ドラッグ／中ボタン／ホイールで画面移動、`Ctrl`＋ホイールで拡大縮小（☰でホイール＝拡大縮小にも切り替え可）、`Shift+1`全体表示、`Shift+2`選択を表示、`Shift+0`で100%、`Ctrl+F`検索、`Ctrl+L`ロック、`Ctrl+]`/`[`で重なり順、整列6種・等間隔2種、自動整列（上→下／左→右）

ショートカットの一覧はアプリ内の「？」（使い方）にある。

### 選択中トピックへの直接入力（日本語入力対応）

マウス環境（`pointer: fine`）では、トピックを1つ選んでいる間、編集用の`textarea`を透明のままトピックの位置でフォーカスしておく。文字の入力、または日本語入力の変換開始（`compositionstart`）を検知した瞬間に、同じ`textarea`を見える状態に切り替えて編集にする。フォーカスが既に入力欄にあるため、変換中の文字が途切れない（表計算ソフトと同じ方式）。タッチ環境ではこの仕組みを使わない（ソフトウェアキーボードが勝手に開くため）。

## マインドマップの配置

- 根の中心を保ったまま、文字から各トピックの大きさを計算し、部分木の高さ（「下」は幅）を積み上げて並べる（右・左右・下）
- 「左右」では、第1階層に左右どちらかを保存する（`side`）。子を足すときは、その時点でトピックの少ない側に付ける（既存の枝が勝手に反対側へ移らないように）。貼り付け・テキストから作った木は、子孫の数で釣り合うように振り分ける
- 枝の色：第1階層ごとに6色を順に割り当て、子孫は親の色を受け継ぐ（トピックごとに色を指定すると上書き）。枝の太さは階層で3→2→1.5
- 深さで見た目が変わる：中心＝塗りつぶし、第1階層＝薄い塗り＋太い枠、それ以下＝ごく薄い塗り＋細い枠

## 線の形

- 端は「ノード＋辺（上下左右／自動）」か「自由な点」。自動の辺は、2つのノードの位置関係から向かい合う辺を選ぶ
- カギ線：候補の経路（曲がり1〜2回、外側を回る迂回4通り）を作り、長さ・曲がりの数・端のノードとの重なり・折り返しで採点して一番良いものを選ぶ。角は丸める。向かい合った辺のずれが3px未満なら段差を作らず直線にする
- 自由な矢印（矢印ツールで何もない所から引いた線）は直線で作る
- ラベルは経路の中間点に、背景色の下地付きで置く

## 描画の仕組み

見た目は「表示リスト」（`path`／`text`／`image`／平行移動`g`の配列）として1か所で作り、画面（SVGの要素）とPNG書き出し（Canvas 2D。`Path2D`で同じパス文字列を描く）の2通りで描く。**画面と書き出しの見た目が必ず一致する**。SVG書き出しは画面用と同じ関数でSVG要素を作り`XMLSerializer`で文字にする。

- 文字の折り返しはCanvasの`measureText`で測って自前で行う（英単語は途中で切らない、句読点・閉じ括弧は行頭に来ないよう前の行にぶら下げる）。画面・書き出しとも同じ行分けになる
- 色はテーマのCSS変数を読んで実際の色コードに解決してから描く。テーマが変わると（`sideops:themechange`）読み直して全体を描き直す。書き出しで「白地（印刷・資料向け）」を選ぶと、テーマに関係なく印刷向けの配色（白背景・濃い文字）で描く
- 描き直しはノード・線ごとに「見た目の鍵」を比べ、変わったものだけ作り直す。移動は`transform`だけ書き換える
- 操作用の表示（選択枠・ハンドル・接続点・ガイド線など）は別の層に描き、書き出しには含めない
- 重なり順：フレーム（いちばん下）→ ノード（配列の順）→ 枝 → 線

## データ構造（IndexedDB・DB名`sideops_mindframe`・DB version 1、すべて`keyPath: 'id'`）

```
boards { id, title, kind(mindmap|flow|ui|free), nodes[], edges[], settings{grid,snap,guides}, createdAt, updatedAt }
images { id, boardId, blob, type, name, w, h, createdAt }
views  { id(=boardId), x, y, zoom }     … 最後に見ていた位置（書き出しには含めない）
meta   { id, value }                     … lastFullExportAt、prefs{wheel, inspector}
```

ノード（`boards.nodes[]`、配列の順が重なり順）：

```
共通   { id, type, x, y, w, h, text, style{color,fill,stroke,sw,fs,bold,align,opacity}, locked }
shape  … shape（rect|round|pill|diamond|para|doc|cyl|sub|hex|ellipse）
ui     … ui（部品の種類）, on（オン／選択中の表示）
topic  … parent, order, collapsed, layout（right|both|down。根だけ意味を持つ）, side（l|r|''）
frame  … device（phone|tablet|pc|free）
image  … imageId, iw, ih（元の画像の大きさ）
```

線（`boards.edges[]`）：`{ id, from, to, route(elbow|straight|curve), arrow(end|none|start|both), label, style{color,stroke,sw} }`。端は`{ node, side(a|t|r|b|l) }`か`{ x, y }`。

- `style`は指定された値だけを持ち、無いものは種類ごとの既定値（トピックは「自動」＝階層・枝で決まる）
- ボード1つを1レコードで保存する（自動保存の単位＝ボード）。画像はBlobのまま別ストアに置き、ノードからIDで参照する

## ID方式

- ボード・画像：`mf_YYYYMMDD_HHMMSS_<英数小文字4桁>`／`im_…`（MANUSCRIPTと同じ方式）。作成時に1回だけ発行し、エクスポート・インポートでも変えない（例外は「複製」とIDの衝突時のみ）
- ノード・線：`n_<英数8桁>`／`e_<英数8桁>`。ボードの中で一意

## テキストから図を作る（外部AIとの連携）

「テキストから作成」（一覧・新規ボード）と「テキストから図を追加」（エディタの☰）で、貼り付けた文字から図を作る。形式は自動判定（1行目が`flowchart`/`graph`ならMermaid、`mindmap`ならMermaidのマインドマップ、それ以外は箇条書き）。AIの返答にありがちな`` ```mermaid ``` ``の囲みは外して読む。

- **箇条書き → マインドマップ**：Markdownの見出し（`#`）とリスト（`-` `*` `+` `・` `1.` `①`など）、インデント（タブ・全角スペース可）から木を作る。階層の飛び（例：`#`の次に`###`）は1段に丸める。一番上が1つならそれが中心、複数なら「中心テーマ」を足す
- **Mermaid → フローチャート**：よく使う記法の範囲に対応。ノードの形（`[]` `()` `([])` `[[]]` `[()]` `(())` `{}` `{{}}` `[//]` `[\\]` `>]`）、線（`-->` `---` `-.->` `==>` `<-->` `--o` `--x`、長さ違い）、ラベル（`-->|文字|`・`-- 文字 -->`）、`A & B --> C`、`;`区切り、`%%`コメント、front matter。`classDef`・`style`・`click`などの装飾と`subgraph`（枠は作らず中身だけ取り込む）は読み飛ばす。解釈できない行は数を表示して飛ばす
- 作った図は**自動整列**して置く。今のボードに追加する場合、既存の図と重なる位置なら全体の右側に並べる
- キャンバスに直接貼り付けても同じ判定をする：Mermaidは図に、箇条書き（2行以上で記号・字下げあり）はマインドマップに、それ以外はテキストノードに。トピックを選んで貼ると、その子として追加する
- **AIへの依頼文**：モーダル内の「AIに作ってもらう」で、テーマを差し込んだ依頼文（マインドマップ用＝字下げ箇条書きで出力／フローチャート用＝Mermaid flowchart TDで出力）をコピーできる。SCRIBIT・MANUSCRIPTと同じく、アプリ自体はAPIを持たない

### 自動整列（階層型）

Sugiyama法の簡易版：①深さ優先探索で戻り辺を反転して閉路を除く→②最長経路法で層を割り当て（入口だけのノードは行き先の直前まで下げる）→③2層以上またぐ辺に中継点を挟む→④重心法で層内の並びを上下交互に8回並べ替え（交差を減らす）→⑤隣の層の重心へ寄せつつ、並び順と最小間隔を守って座標を決める（左詰め・右詰めの2解の平均）。流れに沿う線は決まった辺から出入りさせ（上→下なら下→上）、流れに逆らって戻る線（ループ）は図形を横切らないよう外側（上下の流れなら右、左右の流れなら下）を回す。図形を2つ以上選んで詳細パネルの「自動整列」からも使える。

## 書き出し

| 操作 | 内容 | ファイル名 |
|---|---|---|
| 書き出し → 画像（PNG／SVG） | 範囲：ボード全体／選択中／画面フレーム1つ。配色：今のテーマ／白地（印刷向け）／背景なし。PNGは1〜3倍（辺8192px・4000万画素を超えるときは倍率を下げて通知） | `<ボード名>[_選択／_フレーム名]_YYYYMMDD.png/.svg` |
| 書き出し → 箇条書き（Markdown） | マインドマップ（トピック）を入れ子リストで。コピーかファイル保存 | `<ボード名>_YYYYMMDD.md` |
| 書き出し → Mermaid | 図形・トピック・付箋・テキストと線を`flowchart`で（線が主に横向きなら`LR`）。GitHub・Notionなどに貼ると図になる | `<ボード名>_YYYYMMDD.mmd` |
| このボードをJSONで書き出し | ボード1つ（画像はBase64で同梱） | `mindframe_<ボード名>_YYYYMMDD.json` |
| ☰「すべてをエクスポート」 | 全ボードと画像 | `mindframe_backup_YYYYMMDD_HHMMSS.json` |

JSON形式：`{ app:"sideops_mindframe", schemaVersion:1, scope:"board"|"all", exportedAt, boards[], images[{ id, boardId, type, name, w, h, createdAt, data }] }`。ファイル名の禁則文字はMANUSCRIPTと同じ規則で全角に置き換える。

コピー（`Ctrl+C`）したノードは、クリップボードに独自形式（`application/x-sideops-mindframe`）と文字（トピックは箇条書き）の両方で入る。ほかのアプリに貼ると箇条書きとして使える。

## インポート（JSON）

件数（新規／同じIDあり、画像）を表で確認してから取り込む。同じIDのボードがあるときは4択（MANUSCRIPTと同じ）：更新日時が新しい方を残す（既定）／上書き／別のボードとして複製（新ID・名前に「（複製）」）／取り込まない。上書きではそのボードの画像を入れ替える。画像IDが手元の別の画像とぶつかる場合は新しいIDにして付け替える。

## フールプルーフ

**保存まわり**
- 自動保存（入力停止から600ms、Promiseチェーンで直列化）。Stageを閉じる合図（`sideops:stage-closing`）・`pagehide`・`visibilitychange`・一覧へ戻るとき・`Ctrl+S`でも即保存。保存待ちがあれば`beforeunload`で確認。失敗したら未保存に戻して次の機会に再試行し、容量不足の可能性を通知
- **別タブとの上書き事故の防止**：保存の直前にDBの更新日時を確かめ、自分が読み込んだ後に別の画面が保存していたら黙って上書きせず、「こちらで上書き／こちらを別のボードとして保存／相手の内容を読み込む」を選ばせる
- 起動時に`navigator.storage.persist()`を要求。☰で使用量・画像枚数を確認でき、8割を超えたら警告。最後の全件エクスポートから7日以上で☰に印（MANUSCRIPTと同じ）
- IndexedDBが使えない環境では、一覧の上に「保存できません」の帯を出し、保存状態の表示も変える（画面は使える）
- 使われなくなった画像は、ボードを閉じたとき・起動時に削除する（元に戻す履歴はボードを閉じると消えるため、この時点なら安全）

**編集・操作**
- 元に戻す／やり直す：100回まで。作成と最初の入力は1回にまとめる。矢印キーでの微調整は続けて押した分を1回にまとめる
- 削除は`Ctrl+Z`で戻せる。3個以上消したときは件数と戻し方を通知。トピックは子孫ごと消える
- **ロック**：動かす・消す・書き換える・スタイル変更を止める。ロック中のノードの上からドラッグすると空白と同じ扱い（範囲選択／スマホは画面移動）になり、下敷きの画像の上で作業できる
- ドラッグ中に`Esc`で取り消し（ドラッグ前に戻す）。指を離した合図を取りこぼしても、次の押下で前の操作を取り消してから始める
- トピック選択中でも、表示の切り替え（`Shift+1/2/0`）は文字の入力より優先する（「!」が入って書き換わる事故を防ぐ）
- タッチで編集を始めた直後の0.45秒は、後追いのタップ（マウス互換のクリック）を入力欄で受けない（文字の全選択・カーソル移動が起きて内容が置き換わるのを防ぐ）
- 1ボードのノードは3,000個・線は5,000本まで（超える貼り付け・取り込みは止めて案内）。1ノードの文字は4,000字まで。座標は±200,000に制限
- 画像はPNG/JPEG/WebP/GIF・5MBまで。実際に画像として読み込めるか確認してから保存。一度に20枚まで。枠外へのドロップでブラウザが画面を離れないよう`drop`を止める（JSONを落とした場合はインポートへ案内）
- 文字の表示はSVGの`textContent`とDOMの`textContent`だけ（`innerHTML`に利用者の文字を入れない）。読み込んだデータは種類・値の範囲・参照先を1件ずつ検証して正規化（親が無い・循環しているトピックは切り離す、端のノードが無い線は捨てる）

**インポート・書き出し**
- JSONは`.json`のみ・200MBまで。`app`名が違うもの・アプリより新しい`schemaVersion`は拒否。不正なものは1件ずつスキップして件数を表示
- インポートは開いているボードを閉じて（保存して）から行う（開いたまま上書きされないように）
- 書き出しはボードの内容を保存してから作る

## 既知の注意点・未対応

- 回転・グループ化はない（フレームで代用）。フレームは中身を切り抜かない（はみ出しても表示される）
- カギ線は端の2つのノードだけを避ける（途中の他のノードは避けない）
- Mermaidは`flowchart`/`graph`と`mindmap`の主な記法のみ。`subgraph`は枠を作らない。新しい記法（`A@{ shape: … }`）は未対応
- SVG書き出しの文字は閲覧する環境のフォントで表示される（IBM Plex Sans JPが無い環境では別のフォントになる）。PNGは画面と同じフォントで描く
- ノードの独自形式のクリップボードはChrome系ブラウザ同士が前提。使えない場合は同じページ内のコピー（アプリ内の控え）で代用し、他のページでは箇条書きの文字として貼られる
- 選択中トピックへの直接入力（日本語入力）はマウス環境のみ。スマホは「編集」かダブルタップ
- 同じボードを2つのタブで同時に編集した場合は、保存時に確認ダイアログが出る（自動で混ぜ合わせはしない）
