# アプリ：DONE MORE（`apps/done-more.html`）タスク＆ガントチャート管理 仕様書

## 概要

タスクパネル（`task-panel-left`）が見た目のみでデータ機能を持たないため、データ本体を持つ専用アプリとして実装。タスクパネル側との連携（完了チェックのみの簡易プレビュー化）は未着手（`ダッシュボードパネル群_仕様書.md`参照）。

正式名称は「DONE MORE」。ファイル名（`apps/done-more.html`）・DB名（`sideops_donemore`）・画面表記まで内部識別子ごと統一されている（開発時の作業名「タスクマネージャ」からの改称）。カバー画像は`apps/img/done-more.jpg`。

## データ構造（2階層、IndexedDB本実装・DB名`sideops_donemore`）

- **プロジェクト**：プロジェクト名＋色（グループの単位）
- **タスク**：必ずいずれかのプロジェクトに属する。タイトル・開始日・終了日・完了フラグ

## 画面

一覧タブ（プロジェクトごとにグルーピングしたタスクリスト、完了チェック・編集・削除）とガントタブ（行＝プロジェクト単位、同じ行に複数タスクのバーを時系列に配置）をタブ切り替え。ガントは外部ライブラリを使わない自前実装。

ヘッダーは`// DONE MORE`・一覧／ガントの切り替え・「＋ プロジェクト」・「＋ タスク」・☰ を1段に並べる。幅560px以下（スマホの縦向きなど）では2段にする（2026-10-06〜。以前は右にはみ出していた）：1段目＝タイトルと☰、2段目＝一覧／ガントの切り替え（左）と追加ボタン（右）。切り替えと追加ボタンを`.bar-tools`でまとめ、狭い画面では`.bar-right`を`display: contents`にしている。

## ガント表示のバリデーション（フールプルーフ）

- 同一プロジェクト内でタスクの日付が重複する場合は保存前に警告し、再設定を促す
- 「終了日と次タスクの開始日が同じ日」はバトンタッチとして許容し、それ以外の重なり（内包・部分オーバーラップ）だけをNGとする。判定式：「新タスクの開始日 < 既存タスクの終了日 かつ 新タスクの終了日 > 既存タスクの開始日 → NG」
- 終了日<開始日は保存不可
- タイトル・日付未入力は保存不可
- プロジェクト削除時は紐づくタスク件数を明記した連鎖削除警告

## 完了したタスクを片付ける（2026-10-10〜）

完了したタスクは溜まる一方なのに、消し方は1件ずつ🗑か、プロジェクトごと全部かの両極端だったため、☰に「完了したタスクを片付ける」を足した。

- モーダル（`#cleanupOverlay`）に、**完了にしたタスクだけ**をプロジェクトごとに並べる。まだ終わっていないタスクは出さないので、選べない（ユーザーと決めた歯止め）
- はじめは何も選んでいない。行のチェックで選ぶ。プロジェクトの見出しのチェックで、そのプロジェクトの完了したタスクをまとめて選ぶ／外す（一部だけなら「一部」の表示）。［すべて選ぶ］［すべて外す］もある。「選択中 n件」を出す
- 確認文には「何が危ないか」を箇条書きで出す（2026-10-10、ユーザーの指定）：件数とプロジェクトの数／元に戻せない（ゴミ箱はない）／同期を使っている場合は、次の同期でほかの端末からも消える（アプリからは同期の状態を読めないため「使っている場合は」と書く）／まだ終わっていないタスクは含まれていない。ボタンは「n件を削除する」
- **20件以上（`BULK_DELETE_TWICE`）では削除ボタンを2回押させる**：確認文に「件数が多いため、削除ボタンは2回押します。」と書き、1回目でボタンが「もう一度押すと削除します」に変わって0.7秒押せなくなる（ダブルクリックで2回目まで通らないように）。閉じるとボタンの文字は「削除する」に戻る（1件ずつの削除と同じ確認ダイアログを使うため）
- 消す直前に「今も完了か」を確かめ直し、まとめて1つの書き込み（トランザクション）で消す。途中で失敗したら何も消えない
- キャンセルでは片付けの画面に戻り、選んだまま。消したら片付けの画面も閉じる。Esc・スマホの戻るボタンで閉じる（`.modal-overlay`なので、戻る操作の仕組みがそのまま効く）
- 確認は`D:\dev\sideops_sync_verify\bulkdel_e2e.dart`（2026-10-10）

## ガント描画方式

複数日タスクは「開始日マスの右半分〜終了日マスの左半分」だけを描画し、境界日はバー同士が隙間を挟んで隣り合う（中間日はフル幅のまま）。単日タスクはバーではなくマス中央の●として描画し、同日に複数あっても●は1個だけ表示する（プロジェクト色・完了状態の見た目は継続反映）。●をクリックしたとき、その日のタスクが2件以上あれば小さな選択ポップアップを出し、選んでから編集画面へ遷移する。

（この描画方式は、境界日で2本のバーが同じ位置に描画され後勝ちで隠れる不具合、および同日複数の単日タスクが真上に重なる不具合の修正結果である。）
