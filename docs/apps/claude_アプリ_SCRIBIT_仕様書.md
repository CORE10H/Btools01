# アプリ：SCRIBIT（`apps/scribit.html`）AI代書支援ツール 仕様書

## 概要

記事執筆をAIに代書させる際の一連の作業を支援するツール。全体は5ステップだが、**アプリが担うのは①②④のみ**で、③（外部AIでの生成）と⑤（LLMのプロジェクトナレッジへの格納）は意図的にアプリの外・人力のフローとして設計している（静的HTMLで完結させる方針上、外部AI APIやアップロード連携までは持たない）。

1. **①下書きを書く**（アプリ内）：本文をテキストエリアに書く。入力から800ms後にデバウンス自動保存
2. **②プロンプトを合成する**（アプリ内）：テンプレートを選び「合成する」を押すと、テンプレート内の差し込み位置に①の本文を差し込んだ完成プロンプトを表示。コピーボタン付き（クリップボードAPI失敗時は`execCommand('copy')`にフォールバック）
3. **③AIで生成する**（人力・アプリ外）：②のプロンプトを外部AIに貼り付けて生成させる
4. **④生成物をテキストファイルに変換する**（アプリ内）：③の生成結果を貼り付け欄に貼ると、「タイトル_日付.md」のファイル名でMarkdownファイルとしてダウンロードできる
5. **⑤LLMのプロジェクトナレッジに格納する**（人力・アプリ外）：④でダウンロードした`.md`ファイルを手動でアップロードする

## データ構造（IndexedDB本実装・DB名`sideops_scribit`）

- **テンプレート**：名前＋固定文面（差し込み位置`{{下書き}}`を1箇所含む）。用途別の書き分けはテンプレートを複数登録することで対応する方針（1件の下書きから作れるプロンプトは1本のみで、テンプレート内に複数の差し込み欄は持たない、というシンプル構成）
- **下書き**：タイトル・本文・使用テンプレート・生成結果（Markdown）・状態（進行中／完了）。①〜④を一周した下書きは削除せず「完了」フラグを立てて一覧で区別するだけの履歴として残す

## 画面構成

DONE MOREと同じ「1画面内タブ切替え」方式（一覧→クリックで編集画面）。編集画面は①〜⑤の各ステップを縦に並べたブロック構成で、③⑤は手順として画面上に案内文だけを表示し、実際の入力欄は持たない。

## フールプルーフ

- テンプレート本文に差し込み位置`{{下書き}}`が無いと保存できない（合成時に必ず失敗するミスを事前に防ぐ）
- ①の本文が空のまま合成を実行できない
- ④の貼り付け欄が空のままダウンロードできない
- ダウンロードファイル名は禁則文字（`/ \ : * ? " < > |`）を自動的に全角へ置換し、タイトル未入力時は既定名にする
- テンプレート削除時は使用中の下書き件数を明記して警告（下書き自体は削除しない）
- 最後の1件のテンプレートは削除不可（下書きが作れなくなる事故を防止）
