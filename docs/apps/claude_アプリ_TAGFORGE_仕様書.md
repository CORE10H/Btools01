# アプリ：TAGFORGE（`apps/tagforge.html`）画像生成プロンプトの組み立て 仕様書

## 概要

画像生成（WAI-illustrious-SDXL など、Danbooru タグ式のモデル）のプロンプトを作るための補助ツール。先天的アプリ（`builtin`）。2026-11-20に新設。

**カテゴリごとのワードリストから使いたい語を選ぶ → 組み立ての欄で順番・強さを整える → コピーする**、の流れ。

- 名前：TAGFORGE（ユーザーから名前の指定がなかったので Claude が付けた。変えるときは`BUILTIN_APP_CHOICES`・`<title>`・`// TAGFORGE`・カバー画像を直す）
- ランチャー表示名：`TAGFORGE`（`BUILTIN_APP_CHOICES`）。カバー画像は`apps/img/tagforge.jpg`（900×506。`D:\dev\sideops_sync_verify\cover_tagforge.dart`が`icon_src/tagforge.html`のキャンバスで描いて書き出したもの）
- 1ファイル（HTML＋CSS＋JS）。外部ライブラリなし（並べ替えのドラッグも自前）
- `<head>`の先頭で`sideops-theme-bridge.js`（テーマ・同期の印・戻るボタン）を読み込む
- 外部のAPIは呼ばない。画像の生成はアプリの外（人が貼り付ける）

### ユーザーの依頼（2026-11-20）

- 各カテゴリから使いたいワードを選択し、プロンプトとして組み、コピーする
- ワードは「mdファイルをインポートしてワードリストに追加」と「ツール内でワードリストに追加」の2通り
- ワードリストは並べ替えできる
- 選択したワードを組むときにも順番を入れ替えられる
- 定型文の機能（作業の途中で追加の依頼）
- 単語を作らせる LLM 向けのプロンプトをコピーボタンですぐ使えるように（データはブラウザ内だけでよい）→「ワード生成プロンプト」（2026-11-20）
- 人数を増やして人物ごとの特徴を付けたい（全員に同じ特徴が付いてしまう）→ 区画分け（2026-11-20。下の「区画」）

## 画面

```
┌ // TAGFORGE ─────────────────── [MD取り込み] [☰] ┐
│ カテゴリ │ 品質 ✎   [検索] [編集・並べ替え] [＋ワード] │
│ 品質 ②6  │ [masterpiece][best quality][newest] …   │
│ 人数 ①5  │                                          │
│ …        │                                          │
├ 組み立て PROMPT 3・NEGATIVE 2 ▾ ───────── [定型文] ┤
│ PROMPT  6語・101文字    [＋人物][コピー][クリア] │
│  共通（全員）[masterpiece][2girls]                   │
│ ▌人物1 入れ先 ✎ [blue hair][school uniform]         │
│  人物2 ✎ [pink hair :1.2][hoodie]                    │
│  （選んだチップの操作：◀ ▶ − 1.2 ＋ 1.0に 移す… 外す 閉じる）│
│  区画の区切り方 [BREAK で区切る ▾]（人物の区画があるときだけ）│
│  [リストにない語を直接入力して Enter]               │
│  masterpiece, 2girls BREAK blue hair, … ← コピーされる文字 │
│ NEGATIVE …（同じ形。枠が赤）                        │
└────────────────────────────────────┘
```

- 幅700px以下（スマホ・狭い Stage）：カテゴリは上の横並びのタブ。組み立ての欄は高さの45%まで（PCは48%）
- 組み立ての見出しを押すと、組み立ての欄をたたむ／開く（端末ごとに覚える）

### ワードを選ぶ

- ワードのチップをタップ（クリック）すると組み立てに入る。もう一度押すと外れる
- 入る欄は、カテゴリが「ネガティブ用」なら NEGATIVE、それ以外は PROMPT の「入れ先」の区画（下の「区画」）
- 押したワードが入れ先の区画（ネガティブ用なら NEGATIVE）にあれば外す。NEGATIVE へ移してあった語も、押せば外す。ほかの人物の区画にだけある語は、入れ先にも足す（2人とも smile、など）
- 選んだワードは色が付く（入れ先の区画にある＝水色、NEGATIVE＝赤）。ほかの区画にだけある語は点線の枠と区画の名前。カテゴリの横に選んだ数のバッジ
- 検索欄：全カテゴリから探す。スペースで区切ると「すべてを含む」。ワードの文字と説明の両方を見る。結果はカテゴリごとに分けて出す

### 組み立て

- チップをドラッグ（スマホは長押ししてから動かす）で順番を入れ替える。区画・NEGATIVE をまたいで動かせる（空の区画にも置ける）
- チップを押すと操作の段が出る：◀ ▶（同じ区画の中で1つ前・後ろへ）、− ＋（強さを0.1ずつ。0.1〜2.0）、1.0に、移す…（ほかの区画・NEGATIVE へ。移す先に同じ語があれば重ねずに外すだけ）、外す、閉じる。押したチップの区画が入れ先になる
- 「直接入力」：リストにない語をその場で足す（リストには保存しない。PROMPT は入れ先の区画へ）。カンマで区切ると複数。リストにある語と同じ文字なら、そのワードとしてつなぐ（選んだ印が付く）。同じ区画にもうある語は足さない
- 中身は端末ごとに覚える（localStorage `sideops_tagforge_tray`）。開き直しても残る
- 上限：全部の区画と NEGATIVE を合わせて300語

### 区画（2026-11-20〜）

人数を増やしたとき、特徴が全員に付いてしまう（concept bleeding）のを減らすため、PROMPT を「共通（全員）」と「人物1・人物2…」に分ける。SDXL の仕組み上、区切っても完全には防げない（領域指定の機能があればそれが最も効く）。

- ［＋ 人物］で人物の区画を足す（6つまで）。足した区画が入れ先になる
- 入れ先：ワードを押したときに入る区画。区画の見出し・空いたところを押すと入れ先になる（左の線が水色・「入れ先」の印）。組み立ての見出しにも「入れ先：人物1」
- ✎：区画の名前を変える（例：左の子。コピーする文字には入らない）・区画を消す（中に語があれば確かめる）。共通は消せない
- 人物の区画がないときは、今までと同じ見た目（区画の見出しを出さない）
- 「区画の区切り方」（人物の区画があるときだけ出す。端末ごと。初期は BREAK）
  - BREAK で区切る：`共通 BREAK 人物1 BREAK 人物2`
  - ADDCOMM＋BREAK（領域指定）：`共通 ADDCOMM 人物1 BREAK 人物2`（Regional Prompter の共通プロンプトの書き方）
  - 区切らず1本につなぐ：`, `でつなぐ（区画ごとに語がまとまるだけ）
  - 中身が空の区画は飛ばす。共通が空なら ADDCOMM を付けない
- ユーザーの環境：SeaArt で WAI-illustrious-SDXL。SeaArt で BREAK・ADDCOMM がどう扱われるかの公式の説明は見つからなかった。ユーザーが3つの書き方を試し「どれも分かれてはいる。全部に（片方の）フードが付く」と報告（2026-11-20）。どれが効くかはユーザーが比べる

### コピーする文字の作り方（`formatItem`）

1. ワードの文字（組み立てた後にワードを直していれば、直した後の文字）
2. 「_ をスペースにしてコピー」（初期はオン）：英字を含む語の`_`をスペースに（`long_hair`→`long hair`。`^_^`のような顔文字、`<lora:…>`はそのまま）
3. 「( ) を \( \) にしてコピー」（初期はオン）：キャラ名の括弧をエスケープ（`ganyu (genshin impact)`→`ganyu \(genshin impact\)`）。すでに`\(`のものは二重にしない。全体を`( )`・`[ ]`・`< >`で囲んだ語（強調・LoRAなど、わざと書いた書式）はそのまま
4. 強さが1.0以外なら`(語:1.2)`
5. `, `でつなぐ

2と3の設定は☰の中。端末ごと（localStorage `sideops_tagforge_prefs`）。

### 定型文

よく使う組み合わせ（品質タグ一式・ネガティブ一式など）を名前を付けて保存し、呼び出す。

- 組み立ての見出しの［定型文］で開く
- 保存：今の組み立て（全部の区画と NEGATIVE、順番・強さも）を名前を付けて保存。同じ名前があれば、上書きするか確かめる
  - 「入れ先の区画だけを保存する」：入れ先の区画の中身だけを（共通として）保存する。NEGATIVE は入れない。人物1人分の定型文を作る用
- 「追加」：今の組み立てに足す（同じ語は足さない）。人物の区画を持つ定型文は、共通の部分を共通へ、人物の区画を新しい区画として足す（6つを超える分は足さずに知らせる。同じ名前の区画があれば人物n の名前にする）。区画のない定型文は今の入れ先の区画へ（人物1人分の定型文を人物2に入れる、など）
- 「置換」：今の組み立て（区画ごと）と入れ替える（組み立てが空でなければ確かめる）
- 一覧では、区画のある定型文に「人物n」の印と区画ごとの中身を出す
- ✎：名前の変更・「中身を今の組み立てで上書きする」（確かめる）・削除（確かめる）
- ≡ をドラッグ（スマホは長押し）で並べ替え
- 定型文はワードのIDと文字の両方を持つ。ワードを消しても、文字で呼び出せる（直接入力の扱い）

## ワードリストの編集

- 右上の［編集・並べ替え］で編集の状態にする（チップの枠が点線、上に案内）
  - ワードをタップ：編集（文字・説明・カテゴリ。別のカテゴリへ移すと末尾に付く）・削除
  - ワードを長押し（PCはドラッグ）：並べ替え
  - カテゴリも長押し（PCはドラッグ）で並べ替え
- 編集の状態のときは、タップしても組み立てに入らない（並べ替えの途中の誤選択を防ぐ）。検索中は並べ替えない
- ［＋ ワード］：1行に1語でまとめて足す。`ワード | 説明`で説明も。同じカテゴリにある語は飛ばす。1回500行まで
- カテゴリ：［＋］で作る、見出しの ✎ で名前・ネガティブ用の切り替え・削除。同じ名前は作れない
  - ネガティブ用を切り替えても、組み立て済みの語の欄は変えない（これから選ぶ語の行き先だけ変わる）
- 消したワードが組み立て・定型文に入っていたときは、文字だけ残す（直接入力の扱い）

## MD取り込み

右上の［MD取り込み］。ファイル（.md・.markdown・.txt、1MBまで）を選ぶか、貼り付ける（スマホでも使えるように）。

### 書き方

```
# 髪型
- long hair | ロングヘア
- ponytail | ポニーテール

# ネガティブ [neg]
- worst quality
```

- `#`〜`######`の見出し＝カテゴリ。同じ名前（大文字・小文字・前後の空白は区別しない）のカテゴリがあれば、そこに足す
- 見出しに`[neg]`（`[negative]`・`[ネガ]`・`[ネガティブ]`、全角の`［］`も可）でネガティブ用。新しく作るカテゴリにだけ効く（既存のカテゴリの設定は変えない。確認の画面に書く）
- 見出しより前の語は「未分類」
- 1行＝1語。行頭の`-` `*` `+` `•` `・` `1.` `1)`、チェックボックス`[ ]` `[x]`、引用の`>`は外す。語を囲む`` ` ``、行末の`,` `、`も外す
- 説明の区切りは、前後にスペースのある`|`か、全角の`｜`。`[cat|dog]`のような書き方は壊さない
- 表の行（`| ワード | 説明 |`）も読む。区切りの行と、1列目が「ワード」「タグ」「word」などの見出しの行は飛ばす
- コードの囲み（```` ``` ````）の行・`---`・1行の HTML コメントは飛ばす（囲みの中の行は語として読む）
- 「カンマ区切りの行を、1語ずつに分けて取り込む」（初期はオフ）：`monochrome, greyscale`を2語に。囲み（`( )`・`[ ]`・`< >`）の語は分けない。分けたときは説明を付けない
- 同じカテゴリにある語・ファイルの中で重なった語は飛ばす

### 流れと歯止め

1. ［中身を確かめる］：カテゴリごとに「新規／既存」「NEG」「追加する数」「重複で飛ばす数」を表で出す
2. ［n 語を取り込む］：1つのトランザクションで書く（途中で失敗したら何も変えない）
3. このセッションの間は「☰ → 直前の取り込みを取り消す」で戻せる（足した語と、新しく作ったカテゴリのうち取り込んだ語しか入っていないもの。sessionStorage `sideops_tagforge_lastimport`）

上限：1回5000語・200カテゴリ・1MB。

### ワード生成プロンプト（LLM用）（2026-11-20〜）

ChatGPT・Claude・Gemini などに貼って、取り込める形の MD を作ってもらうためのプロンプト。外部の API は呼ばない（コピーして人が貼る）。

- 開き方：「☰ → ワード生成プロンプト（LLM用）」、または MD取り込みの画面の［ワード生成プロンプト（LLM用）］
- テーマの欄（空でも可。空なら「（ここにテーマを書いてください）」が入り、コピーした後に書き足せる）
- 「今あるカテゴリの名前を伝える」：カテゴリ名の一覧（ネガティブ用は `[neg]` つき）を足す。LLM が同じ名前の見出しを使えば、取り込んだとき同じカテゴリに入る
- ひな形は直してよい。`{{テーマ}}`・`{{カテゴリ}}` の所に上の内容が入る。［ひな形を初期に戻す］は2回押し
- ［コピー］：ひな形にテーマ・カテゴリを入れてコピー。［MD取り込みへ］：取り込みの画面を開く
- 初期のひな形：テーマ → 「上記のテーマに沿って、WAI-illustrious-SDXL（Danbooru タグ形式）向けの英語のタグを、下記のフォーマットで Markdown として出力」→ フォーマット（`# カテゴリ名`（日本語）、`- タグ | 日本語の短い説明`、ネガティブは `[neg]`、Danbooru に実在するタグ・英小文字・アンダースコアなし、重みなし・1行1タグ、1カテゴリ5〜20個・重ねない、前置きなしでコードブロック1つ）→ 出力例。LLM がコードブロック（```markdown）で返しても、取り込みは囲みの行を飛ばして中を読む
- 保存はこの端末だけ（localStorage `sideops_tagforge_genprompt` に `{ tpl, theme, cats }`。同期しない。ユーザーの希望）

### 書き出し・見本

- 「☰ → ワードリストをMDに書き出す」：同じ書き方の`tagforge_yyyymmdd.md`。そのまま取り込み直せる（控え・別の端末への受け渡し・手で編集して戻す用）
- 「☰ → 見本のワードを入れる」（リストが空のときは画面にもボタン）：品質・人数・髪・目・服装・表情・ポーズ・視線・構図・背景・光・効果・ネガティブの11カテゴリ・73語（WAI-illustrious の推奨の品質タグ・ネガティブを含む）。取り込みと同じ確認の画面を通る

## 並べ替えのドラッグ（`makeSortable`）

組み立てでは、置き場（`zoneSel`＝`[data-zone]`。区画と NEGATIVE の並び）をまたいで動かせる。チップのない所に来たら、その置き場の末尾へ。離したら画面の並びをそのまま組み立てに写す。

ワード・カテゴリ・組み立てのチップ・定型文で共通の部品。

- マウス：5px動かしたら掴む。動かさずに離したらタップ
- タッチ・ペン：280ms長押しで掴む（短く振動）。長押しの前に8px動いたらスクロールとみなしてやめる。掴んでいる間は`touchmove`を止めてスクロールさせない
- 掴んだ要素をその場で動かす（指の下の要素の前・後ろへ。折り返す並びは左右の半分、縦の並びは上下の半分で決める）。端に近づくと自動でスクロール
- 離したとき並びが変わっていれば保存。長押しの後の`contextmenu`は出さない
- キーボード（Enter・Space）の click はタップとして扱う

## 誤作動防止

- クリア：2回押し（1回目で「もう一度押すとクリア」、3秒で戻る）。クリアの後8秒は「元に戻す」
- 削除（ワード・カテゴリ・定型文）は確認のダイアログ。カテゴリは中のワードの数を示し「n件ごと削除」
- 取り込み：確認の画面 → 1つのトランザクション → セッションの間は取り消せる。上限あり
- 入力を捨てて閉じるかの確認：ワードを足す画面（何か書いてある）・ワードの編集（変えてある）・取り込みの確認の画面
- 同じ名前のカテゴリ・定型文、同じカテゴリに同じ語は作らない
