# 一時メモ 仕様書（2026-10-10〜）

## 概要

画面に浮かぶ、小さな書き付け用のメモ。メモアプリ（`apps/memo.html`）とは別物で、Stageには開かない。ヘッダーの ✎ で出し入れする。保存はせず、SIDE-OPS（ブラウザのタブ、またはホーム画面のアプリ）を閉じると中身が消える。

- 本体：`index.html` の `#tempMemo`（`.shell` の外。Stageと同じ理由で、`3D変形とスタッキングコンテキスト_仕様書.md`）・`style.css` の「一時メモ」・`js/temp-memo.js`
- ユーザーの希望（2026-10-10）：「stageに展開するのではなく、onにすると常時画面の何処かに浮いており、移動もできるもの。記憶はせずに、sideopsを閉じると中身が消える。シンプルにメモ書き用」

## 出し入れ

- ヘッダーの ✎（`#tempMemoBtn`。⛶ の左）と、Stageの ✎（`#stageTempMemoBtn`。表示範囲の切り替えボタンの左、スマホでは ✕ の左）。Stageを広げたとき・スマホでアプリを開いているときはヘッダーが隠れるため、Stageにも置いている。どちらで押しても同じ一時メモが出入りし、出ている間は両方の ✎ が光る（`is-active`・`aria-pressed`）
- 一時メモの「－」でも隠せる。隠しても中身は残る
- 出したとき、マウスで使う端末（`pointer: fine`）だけは、すぐ書けるように入力欄へ移る（スマホでは勝手にキーボードを出さない）

## 中身の残し方

| 何を | どこに | いつ消えるか |
|---|---|---|
| 中身 | `sessionStorage` の `sideops_tempmemo_text` | タブ・アプリを閉じたとき（「消す」を2回押したときも） |
| 出ているか | `sessionStorage` の `sideops_tempmemo_shown` | 同上 |
| 位置と大きさ | `localStorage` の `sideops_tempmemo_rect` | 消えない（端末ごと。中身は入れない） |

- IndexedDB には入れず、同期もしない
- `sessionStorage` にしたのは、再読み込みや、Androidのブラウザ（Brave）が裏でタブを捨てて開き直したときに消えないようにするため（ユーザーが「閉じたら消える」を選んだ。2026-10-10）。画面のメモリだけに置くと、これらでも消えてしまう
- 入力は300ms待ってから残す。画面を離れる・隠れるとき（`pagehide`・`visibilitychange`）は待たずに残す
- 既知の振る舞い：PCのブラウザで「前回のセッションから再開」を使っていると、ブラウザを開き直したときにタブと一緒に `sessionStorage` も戻り、中身が残ることがある（ブラウザの機能）
- `sessionStorage` が使えない環境では、そう知らせる（「この端末では、再読み込みでも消えます」）

## 操作

- **動かす**：上のつまみ（タイトルの行）をドラッグ。マウスも指も Pointer Events で同じに扱う（つまみと右下の角は `touch-action: none` で、指で動かしても画面がスクロールしない）
- **大きさ**：右下の角をドラッグ。最小 180×120
- **コピー**：中身をクリップボードへ（`navigator.clipboard`、だめなら古い `execCommand('copy')`）。結果はつまみの行の小さな文字で知らせる
- **消す**：2回押す。1回目で「もう一度で消す」に変わり、3秒たつと元に戻る（消えない）
- キー操作はない（`Esc` でも隠れない。モーダルではないため）

## 画面の中に収める（歯止め）

- 動かしても大きさを変えても、画面の外に出ない（端から8px）
- 画面の大きさが変わったら（回転・ウィンドウの大きさ・スマホのキーボード）、見えている範囲（`visualViewport`）に収め直す。キーボードが出ると、その上に持ち上がる
- 覚えている位置は、ユーザーが動かした結果だけ。収め直しでは書き換えないので、画面が元の大きさに戻れば元の位置に戻る
- 動かしている間は、Stageの中のアプリ（iframe）にポインタを取られないよう、iframeの `pointer-events` を切る（`body.temp-memo-dragging`）

## 重なり（z-index）

Stage（190）・同期の帯（190）より手前の **195**。本体のモーダル（設定 200、ランチャー 250、同期 260〜）より奥。モーダルを開いている間は、その覆いの下になる（モーダルの操作を邪魔しない）。Stageの中のアプリのモーダルは、Stageごと一時メモの下。

## 戻る操作との関係

モーダルではないので `is-open` を使わず（`is-shown`）、`js/back-nav.js` の層として積まない。出し入れで履歴は増えない。戻る操作でStageやモーダルが閉じても、一時メモは出たまま。

## スマホのヘッダー

ヘッダーのボタンが4つになったため、幅の狭いスマホでは1行に収まらず、画面全体が横に広がっていた（393px以下）。ヘッダーを詰めて収めた（`ヘッダーと設定モーダル_仕様書.md`「スマホのヘッダーの詰め方」）。
